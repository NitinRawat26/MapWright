How it works

  1. Profiles: upload samples, schemas or field specs for each system.
  2. Mapping: pick a source and a target; published playbooks decide each field, AI helps only if you ask.
  3. Replay: run real samples through the mapping and check the target payloads.
  4. Review: approve, reject or override rows, then export to Excel, CSV or HTML.
  5. Playbooks: improve the business knowledge in drafts; publishing needs passing tests and a second reviewer.
